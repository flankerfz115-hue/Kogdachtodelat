# Школьный помощник — приложение для айфона

Это сайт, который ставится на экран «Домой» как обычное приложение. В нём есть:
- **«Сейчас»** — какой идёт урок, сколько до конца, что дальше;
- **заметки** и **напоминания** (разовые, каждый день, каждую неделю);
- **уведомления**: перед уроком приходит «09:25 — Физика, каб. 301, дальше Русский язык», утром — расписание на день.

Всё бесплатно: сайт живёт на GitHub Pages, а уведомления присылает GitHub Actions каждые 5 минут.
Заметки и расписание хранятся в репозитории **в зашифрованном виде**, без ключа их никто не прочитает.

## Настройка (один раз, ~10 минут)

### 1. Репозиторий
1. Зарегистрируйся на [github.com](https://github.com).
2. Нажми **New repository** и назови его, например, `school`. Выбери **Public**:
   бесплатный сайт работает только у публичных репозиториев.
3. Нажми **uploading an existing file** и перетащи **всё содержимое** папки `school-pwa`,
   включая папку `.github`. Нажми **Commit changes**.
4. Проверь, что в репозитории есть файл `.github/workflows/notify.yml`. Если его нет,
   нажми **Add file → Create new file**, впиши имя `.github/workflows/notify.yml`
   и вставь туда содержимое файла.

### 2. Сайт
**Settings → Pages**. В Source выбери **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажми **Save**.
Через минуту сайт откроется по адресу `https://твой-логин.github.io/school/`.

### 3. Токен для приложения
Открой [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new):
- **Expiration** — самый долгий срок;
- **Repository access** → *Only select repositories* → `school`;
- **Permissions → Repository permissions**:
  - **Contents** — Read and write
  - **Secrets** — Read and write
  - **Actions** — Read and write

Нажми **Generate token** и скопируй его. Токен показывается только один раз.

### 4. На айфоне
1. Открой адрес сайта в **Safari**.
2. Нажми **«Поделиться»** → **«На экран „Домой“»**.
3. Открой приложение **с иконки** на экране «Домой». Уведомления работают только так (нужен iOS 16.4 или новее).
4. Вкладка **Настройки**:
   - Шаг 1: впиши `твой-логин/school` и токен, нажми **Подключить**;
   - Шаг 2: **Разрешить уведомления**;
   - Шаг 3: **Прислать тестовое уведомление**. Через 1–2 минуты оно придёт.
5. Вкладка **Уроки**: заполни расписание и звонки, нажми **Сохранить расписание**.

## Полезно знать
- GitHub запускает проверку примерно раз в 5 минут, но иногда с опозданием на 5–15 минут.
  Поэтому уведомление может прийти не секунда в секунду.
- Если в репозитории 60 дней не было изменений, GitHub может приостановить расписание.
  Тогда придёт письмо: открой вкладку **Actions** и нажми **Enable workflow**.
- Ключ шифрования виден в Настройках. Он нужен, если захочешь подключить второе устройство.
  Без ключа данные не расшифровать, поэтому сохрани его где-нибудь.
- Когда истечёт срок токена, создай новый и подключись заново: скопируй ключ, нажми
  «Отключить это устройство» и в шаге 1 впиши новый токен и тот же ключ.
